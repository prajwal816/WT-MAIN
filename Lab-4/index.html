Sudoku 6×6

Enter digits 1–6. Each row, column, and 2×3 box must contain all digits without repetition.

Controls Clean UI

Keyboard-friendly input, conflict highlighting, and a backtracking solver.

Tips
- Click a cell and type 1…6 (or Backspace to clear).
- Move with ↑ ↓ ← → or Tab.
- Use Lock givens after you enter the starting clues.
What “Validate” checks
It marks conflicts (duplicates) in any row, column, or 2×3 box, and shows a message if the current grid can be solved.
Customizing
To switch styles: edit CSS variables in :root.
To change puzzle size: update SIZE, BOX_R, BOX_C in JS (this file).
